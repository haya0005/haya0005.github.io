# Hayato Yagi / 八木 颯斗

慶應義塾大学大学院 理工学研究科 高道研究室所属の個人ページです。

**Site:** https://haya0005.github.io/

## 構成

| ファイル | 内容 |
|----------|------|
| `index.html` | ページ本文（About / News / 経歴 / 受賞 / 論文 / 経験 / 連絡先） |
| `styles.css` | スタイル |
| `assets/` | 写真・PDF・スライド・ファビコン |
| `sitemap.xml` / `robots.txt` | 検索エンジン向け |

## ローカル確認

```bash
python3 -m http.server 8000
```

`http://localhost:8000` で確認できます。

## 公開

`main` ブランチへ push すると、GitHub Pages 経由で反映されます。
